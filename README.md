# Amah Martin - Data Analytics Engineer Portfolio

This is the source code for my personal portfolio website. The website showcases my data analytics & engineering work through various sections, including an introductory greeting, a projects section highlighting my GitHub repositories, and a contact form.

## Features

- **Introductory Greeting**: A welcoming message introducing me as a Data Analytics Engineer with focus on enterprise infrastructure and self-service platforms.
- **Projects Section**: A grid displaying my projects
- **About Section**: Details about my professional philosophy, approach to work, career history, and certifications.
- **Contact Section**: Social media links (Email, LinkedIn, GitHub) with icons for visitors to get in touch.

## Setup and Usage

To run the website locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ammartin8/ammartin8.github.io.git
   cd into project
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open your web browser** and visit `http://localhost:5173` to view the website.

## Tech Stack

- **React 19+** with TypeScript
- **Vite 8.x** - Fast build tool and dev server
- **Tailwind CSS v4** - Utility-first styling (pure Tailwind, no custom CSS)
- **Framer Motion 12.x** - Smooth animations and scroll effects
- **React Router DOM** - Client-side routing
- **React Icons** - Icon library for social media links
